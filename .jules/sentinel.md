## 2025-11-25 - Fix Unsafe Subprocess Execution Path Validation
**Vulnerability:** The code previously verified safe path execution using only `.hasPrefix("/")`, leaving it vulnerable to paths containing directory traversal patterns like `/usr/bin/../../tmp/malicious`. Furthermore, checking if a path starts with `/` does not restrict execution to a whitelist of trusted directories, allowing arbitrary bin loading via environment variables.
**Learning:** Always resolve file paths to a canonical form (e.g., using `URL(fileURLWithPath:).standardized.path` in Swift) to neutralize path traversal sequences (`..`) prior to validation.
**Prevention:** Explicitly match against a list of safe directory prefixes using trailing slashes (e.g. `/usr/local/bin/`) to avert partial match bypasses (like `/usr/local/bin2/`), and apply this restriction across all process execution boundaries parsing external variables.
